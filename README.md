# Revira
ReVira é uma plataforma web de zeladoria urbana colaborativa: moradores de Campos Belos (GO) registram problemas da cidade com foto e localização no mapa, recebem um protocolo para acompanhar a solução e a gestão responde por um painel administrativo. Feita com Supabase, é trilíngue (PT/EN/ES), tem proteção antispam e segue a LGPD, com privacidade.
